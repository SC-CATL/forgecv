# Word 导出规范

> 状态：M5 已实现，代码在 `features/export/docx_writer.py` 与 `service.py`。
> 实现不得偏离本规范；需要变更先改本文件。

## 1. 范围

- 唯一导出格式：`.docx`（`python-docx`）。
- 导出源：`resume` 切片提供的渲染数据，`export` 切片不直接读数据库。
- 未来的 PDF / HTML 通过同一份渲染数据另加适配器，不改业务模型。

## 2. 版式

| 项 | 规范 |
|---|---|
| 纸张 | A4（21 × 29.7 cm） |
| 页边距 | 上下 2.0 cm，左右 1.8 cm |
| 正文 | 宋体 10.5 pt，行距 1.15，段后 3 pt |
| 姓名 | 微软雅黑 18 pt 加粗 |
| 求职意向 | 微软雅黑 10.5 pt，灰色 `#5c6a7a` |
| 分区标题 | 微软雅黑 12 pt 加粗，下加 0.75 pt 细线 |
| 条目主标题 | 微软雅黑 10.5 pt 加粗 |
| 时间 | 宋体 9 pt，右对齐 |
| 标签 | 宋体 9 pt，`#2f6fed` |
| 页脚 | 宋体 8 pt，`姓名 · 第 X 页 / 共 Y 页` |

**中文字体必须显式设置** `w:rFonts` 的 `eastAsia` 属性，否则 Word 可能回退导致排版错位。
这是硬性检查项，导出测试会验证生成的 XML。

## 3. 分区顺序

1. 基本信息（姓名、意向、城市、邮箱、电话、GitHub / 博客）
2. 教育经历
3. 工作 / 实习经历
4. 项目经历
5. 技术能力
6. 证书与荣誉
7. 自我评价（可选，默认关闭）

空分区不输出标题，不留空行。

## 4. 条目排版

### 4.1 教育

```text
院校名 · 学历层次 · 专业                          2020.09 – 2024.06
GPA 3.8/4.0 · 主修：操作系统、数据库、编译原理
毕业论文：<标题>（可选）
```

### 4.2 工作经历

```text
公司名 · 职位                                     2022.07 – 2024.09
· 量化成果一（动词开头，含数字）
· 量化成果二
```

### 4.3 项目经历

```text
项目名 · 我的角色 · 方向                          2023.03 – 2023.12
标签：Python · FastAPI · CI/CD · 性能优化
· 亮点条目（问题 → 动作 → 结果）
指标：QPS 1200 · 覆盖率 86% · P99 45ms
仓库：https://github.com/...
```

规则：
- 每个项目最多 4 条亮点，超出按 `sort_order` 截断；
- 指标来自 `project_metrics`，最多展示 4 项；
- 标签最多 6 个，按「语言 → 领域 → 工程实践 → 工具链」排序；
- 仓库链接可选，**不导出** `demo_url` 以外的私密地址。

### 4.4 技术能力

按 `category` 分组，每组一行：

```text
语言：Python（熟练，3 年）· Go（熟悉，1 年）
```

- 熟练度只导出文字，不导出自评分数字；
- 每条技能若挂了证据，可选追加「见项目：XXX」，默认关闭（避免页面过长）。

## 5. 导出前检查

导出按钮触发以下检查，任一失败给出可定位的提示，不静默跳过：

| 检查 | 规则 | 级别 |
|---|---|---|
| 必填字段 | 姓名、至少一条教育、至少一个项目 | 阻断 |
| 时间冲突 | 同一分区内时间区间重叠 | 警告 |
| 空条目 | 标题不为空但没有任何描述 | 警告 |
| 附件路径 | `attachments.path` 指向的文件存在 | 警告 |
| 链接格式 | 只接受 `http(s)://` | 警告 |
| 预计页数 | 超过 2 页提示精简 | 提示 |

## 6. 文件命名与落盘

```text
{姓名}-{目标岗位或“通用”}-{yyyyMMdd-HHmm}.docx
```

- 默认目录：用户「文档/ForgeCV」；
- 同名文件追加序号，不覆盖；
- 导出成功后记录到日志，不写数据库（导出物不是持久化业务数据）。

## 7. 验收

- [ ] 生成的 docx 用 Word 与 WPS 均可打开，中文不乱码、无字体回退。
- [ ] 两种主题（浅色 / 深色）导出结果一致——导出只用打印色，不跟 UI 主题。
- [ ] 空分区、空字段、超长项目名均不破坏版式。
- [ ] 导出内容与简历预览逐项一致。
- [ ] 单元测试覆盖字体设置、分区裁剪、文件名生成。
