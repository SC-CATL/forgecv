# 功能地图

状态口径：已完成 / 开发中 / 计划。功能上线前不从这里删除，只改状态。

## 1. 导航与页面

| 导航 | 页面 | 数据表 | 功能 | 状态 |
|---|---|---|---|---|
| 概览 | `dashboard` | 只读聚合 | 统计卡片、能力雷达、标签分布、健康度摘要 | 已完成（M3） |
| 个人信息 | `profile` | `candidate`、`certificates` | 姓名、求职意向、联系方式、链接与证书 | 已完成（M2） |
| 学历路径 | `education` | `educations` | 学历节点增删改、时间轴顺序、在读状态 | 已完成（M2） |
| 时间轴 | `timeline` | 只读聚合 | 学历 + 工作 + 项目统一时间轴，冲突 / 空档提示 | 已完成（M3，重叠提示） |
| 工作经历 | `experience` | `experiences` | 公司与职位、量化成果条目 | 已完成（M2） |
| 项目库 | `project` | `projects`、`project_metrics` | 项目档案、方向、指标、复盘 | 已完成（M2） |
| 标签管理 | `tag` | `tags`、`project_tags` | 四维标签库、颜色、项目打标 | 已完成（M2） |
| 技能矩阵 | `skill` | `skills`、`skill_evidence` | 分类技能、熟练度、证据链 | 已完成（M3） |
| 技能市场 | `market` | 内置目录，无独立表 | 浏览项目认可技能，一键学习并打「市场认证」标签 | 已完成 |
| 简历版本 | `resume` | `resume_versions`、`resume_items` | 按岗位组条目、实时预览、健康度、JD 覆盖 | 已完成（M4） |
| 导出 | `export` | 无 | Word 导出 | 已完成（M5） |
| 快照 | `snapshot` | `snapshots` | 版本快照、Diff、回滚 | 已完成（M5，快照与 Diff） |
| 设置 | `settings` | `app_settings` | 主题（浅色 / 深色 / 高对比 / 跟随系统） | 已完成（M0） |

## 2. 差异化能力

| 能力 | 说明 | 状态 |
|---|---|---|
| 项目技术标签 | 语言 / 领域 / 工程实践 / 工具链四个维度，可筛选与统计 | 已完成（M2 打标 / M3 统计） |
| 技能—项目证据链 | 每条技能必须关联项目或经历，无证据会被标记 | 已完成（M3） |
| 技能市场 | 内置本项目认可的技能清单，学习后写入技能矩阵并带「市场认证」标签 | 已完成 |
| 工程能力雷达 | 8 维自评聚合，标注「自评」，权重可调 | 已完成（M3，权重固定） |
| 简历健康度 | 时间重叠、空档、无量化、无证据、条目过长 | 已完成（M4，结构与量化规则） |
| JD 覆盖分析 | 本地词表匹配技能与标签，输出覆盖率与缺口 | 已完成（M4，本地词表） |
| 版本快照与 Diff | 任意两版对比条目差异，可回滚 | 计划 |
| 素材库复用 | 条目跨版本勾选组合，换岗位不重写 | 已完成（M4 版本编排） |
| 项目深度档案 | 架构、指标、CI、上线状态、复盘 | 计划 |

## 3. 明确不做

| 不做 | 原因 |
|---|---|
| 在线账号与云同步 | 本地优先，避免隐私与服务器成本 |
| 自动投递简历 | 涉及招聘平台条款与账号安全 |
| AI 自动写简历 | 首版保持可解释、可核对；后续可作为可选插件 |
| 多候选人管理 | 个人工具，单候选人 + 多版本已覆盖需求 |
