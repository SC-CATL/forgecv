# 快速上手

> 当前进度：0.1.0。录入、技能举证、简历编排、Word 导出、快照 Diff 均可用。

## 1. 安装

要求 Windows 10/11、Python 3.12、[uv](https://docs.astral.sh/uv/)。

```powershell
winget install astral-sh.uv      # 已安装可跳过
git clone <仓库地址> forgecv
cd forgecv
uv sync
```

网络慢时先切镜像：

```powershell
$env:UV_DEFAULT_INDEX = "https://pypi.tuna.tsinghua.edu.cn/simple"
uv sync
```

## 2. 启动

```powershell
uv run dev
```

已同步依赖后，也可以双击仓库根目录的 `run.bat`（自动迁移后启动）。

注意：直接用系统 Python 运行 `python main.py` 时，启动器会自动切换到项目 `.venv`；
如果自动切换失败，再用 `.venv\Scripts\python.exe main.py`。
在 VS Code 里执行 `Python: Select Interpreter`，选择 `forgecv/.venv`。

首次启动会自动建库并执行迁移，然后打开主窗口。左侧导航包含：

- **概览**：统计卡片、八维能力雷达、标签分布与改进提示
- **个人信息**：姓名、求职意向、联系方式、链接与证书
- **学历路径**：学历节点、时间轴顺序、在读状态
- **时间轴**：学历 / 工作 / 项目统一时间轴，重叠提示
- **工作经历**：公司与职位、量化成果条目
- **项目库**：项目档案、指标、四维技术标签
- **标签管理**：语言 / 领域 / 工程实践 / 工具链
- **技能矩阵**：分类技能、熟练度与项目证据链
- **技能市场**：项目认可技能清单，一键学习并带「市场认证」标签
- **简历版本**：按岗位勾选条目、实时预览、健康度与 JD 覆盖
- **导出 Word**：选版本、预检、生成 docx
- **版本快照**：保存渲染文本并做两版 Diff
- **设置**：浅色 / 深色 / 高对比主题

建议录入顺序：个人信息 → 学历 → 工作经历 → 标签 → 项目（给项目打标签）→ 技能；
也可以先到「技能市场」学习项目认可的技能，再回技能矩阵补年限、自评分与证据。

其他启动方式：

| 目的 | 命令 |
|---|---|
| 普通启动（不自动迁移） | `uv run app` |
| 只跑迁移 | `uv run app --migrate` |
| 环境自检 | `uv run app --self-test` |
| 环境体检 | `uv run doctor` |
| 写入演示数据（可选） | `uv run python scripts/seed.py` |

## 3. 导出简历

1. 在「简历版本」页新建版本，勾选要展示的条目，必要时上下排序；
2. 在右侧预览确认内容，处理「健康度检查」中的必须项；
3. 打开「导出 Word」，选择版本与输出目录，点击导出；
4. 文件命名为 `姓名-岗位-日期时间.docx`，同名自动追加序号。

「版本快照」页可以保存当前版本，并选择两份快照做文本差异对比。

## 4. 数据在哪

| 内容 | 位置 |
|---|---|
| 数据库 | `%LOCALAPPDATA%\ForgeCV\app.db` |
| 日志 | 程序日志窗口或开发终端 |
| 导出文件 | 默认「文档/ForgeCV」，可在导出页修改 |

数据只存在本机，不联网、不上传、不收集遥测。

## 5. 备份与迁移机器

1. 完全退出程序。
2. 复制 `app.db`（以及同目录的 `app.db-wal`、`app.db-shm`，如果存在）。
3. 在新机器安装并首次启动后，用备份文件替换新生成的 `app.db`。
4. 启动后确认数据完整；版本升级时程序会自动执行迁移。

## 6. 卸载

删除程序目录即可。若不再需要数据，手动删除
`%LOCALAPPDATA%\ForgeCV`，程序不会在注册表或系统目录留下业务数据。
