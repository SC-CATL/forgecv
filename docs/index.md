## 文档约定

1. **单一事实源**：数据以 ORM 模型与 Alembic 迁移为准，`data-model.md` 与之同 PR 更新。
2. **状态透明**：功能状态只有三种——已完成 / 开发中 / 计划，不写模糊的「基本可用」。
3. **里程碑同步**：每个里程碑结束必须更新 CHANGELOG、受影响文档与本页状态。
4. **中文正文**：命令、表名、字段名、代码标识符保持英文原样。
5. **可验证**：只写能落到字段、路径、命令与限制上的内容，不写宣传语。
